---

## 🎯 The Challenge
Governments across India struggle to consolidate citizen feedback and align it with national infrastructure priorities. Development requests live in fragmented systems, leading to misaligned public spending, unaddressed infrastructure gaps, and no way to measure impact.

## 💡 Our Solution — Janvaani
Janvaani (जनवाणी) means **Voice of the People.**

A scalable, multilingual AI platform — designed as a Digital Public Good — that:
1. Aggregates citizen development requests via voice, text, and messaging apps.
2. Analyzes feedback with national demographic and infrastructure data.
3. Surfaces demand hotspots and recommends high-priority projects to policymakers.

## 🏗️ Architecture
| Layer | Technology |
|-------|------------|
| Ingestion | Dialogflow, Cloud Speech-to-Text, WhatsApp API |
| AI Processing | Gemini 1.5 Pro (Vertex AI) |
| Predictive Modelling | Vertex AI AutoML |
| Data | BigQuery, data.gov.in, Census, IMD |
| Geospatial | Google Maps Platform |
| Output | Looker Studio |
| Deployment | Cloud Run, Firebase |
